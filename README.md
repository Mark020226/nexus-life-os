# 🧠 NEXUS Life OS: Sistema Multi-Agéntico de Vida & Segundo Cerebro

> **Plataforma personal de organización integral, aprendizaje acelerado de ingeniería/informática y gestión basada en métricas.**

Desarrollado para centralizar:
- 💡 **Segundo Cerebro (Knowledge Base):** Ingesta automática y clasificación de enlaces, artículos y videos de alto valor.
- 🎓 **Plan Académico UMSA & Informática MIT/Harvard (OSSU):** Monitoreo de materias y habilidades técnicas.
- 📊 **Métricas de Rendimiento Personal:** Sueño, hábitos y energía con análisis estadístico.
- 💰 **Finanzas Inteligentes:** Regla 50/30/20 y control de presupuesto inspirado en metodologías de ingeniería industrial.

---

## 🚀 Inicio Rápido

1. Instalar requerimientos:
   ```bash
   pip install -r requirements.txt
   ```
2. Iniciar el Dashboard interactivo:
   ```bash
   streamlit run src/dashboards/app.py
   ```
